BrutiFi Demo для Windows x64

ВАЖНО: это безопасная учебная демонстрация PBKDF2-HMAC-SHA256.
Программа проверяет только одну введённую строку против встроенной демонстрационной строки.
Она НЕ сканирует Wi-Fi, НЕ читает handshake/PCAP и НЕ подбирает пароли к сетям.

Как получить готовый EXE без установки Rust на свой компьютер:
1. Создай новый пустой репозиторий на GitHub.
2. Загрузи в него все файлы из этой папки, включая скрытую папку .github.
3. Открой вкладку Actions в репозитории.
4. Выбери workflow "Build Windows EXE" и нажми Run workflow
   (если workflow уже запустился автоматически после загрузки, дождись его завершения).
5. Открой завершённый запуск workflow и скачай artifact
   "brutifi-demo-windows-x64".
6. Распакуй архив и запусти brutifi-demo.exe.

Для демонстрации правильная фраза: university-demo-2026.
Если GitHub показывает предупреждение о первом запуске Actions, разреши запуск workflow.

Исходники находятся в src/main.rs.
